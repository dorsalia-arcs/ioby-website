FAQ

よくある質問

無償版と有償版は、どう違いますか？

選べるテーマと書体の数、フォルダを選んで映すスライドショー、動画のくりかえし再生が違います。くわしくは比較表をご覧ください。アラームやメモなど、表にない機能はどちらの版でも使えます。

有償版にするとき、アプリを入れ直す必要はありますか？

ありません。無償版と有償版は同じアプリです。アプリの中で有償版を購入すると、そのまま有償版の機能が使えるようになります。

個人情報は集めていますか？

TKclock は通信を行わず、個人情報を収集・送信しません。購入とライセンスの確認は Microsoft Store が行います。くわしくはプライバシーポリシーをご覧ください。

返金はできますか？

デジタル商品の性質上、購入後の返品はお受けしていません。返金は Microsoft Store の返金手続き・規定に従います。くわしくは特定商取引法に基づく表記をご覧ください。

Mac やスマートフォンでも使えますか？

現在は Windows 版のみです。
